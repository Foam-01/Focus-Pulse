# 📦 Focus Pulse - Pomodoro & Productivity Platform

A full-stack web application designed for focus management, task tracking, and ambient relaxation.  
Includes customizable Pomodoro timer, executive analytics dashboard, dual-theme mode, ambient video relaxation library, and Supabase authentication with 2FA security.

## 🔧 Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript, Vanilla CSS Design System, Lucide Icons
- **Backend**: NestJS, TypeScript, Prisma ORM
- **Database & Auth**: PostgreSQL (Supabase Cloud), Supabase Auth (Google OAuth, GitHub OAuth, TOTP 2FA)
- **Deployment & Hosting**: Vercel (Frontend), Render.com (Backend)

## 🚀 Features

- ⏱️ **Customizable Pomodoro Timer**: Presets (15, 25, 45, 60 mins), direct typing stepper, and session category tags.
- 🎬 **Ambient Video Relaxation Library**: Automatic video popups upon focus completion for stress relief.
- 📊 **Executive Productivity Analytics**: Visual breakdown of focus sessions (Daily, Weekly, Monthly) with streak counters.
- 🎯 **Daily Focus Goal Tracking**: Interactive progress ring and daily target adjustment (e.g. 8 Hours).
- 🌓 **Dual-Theme System**: Seamless toggle between sleek Dark Mode and crisp Light Mode.
- 🔐 **Multi-Factor Security**: Email/Password login, Google & GitHub OAuth, and Google Authenticator 2FA support.

## 🏁 Getting Started

```bash
# Clone repository
git clone https://github.com/Foam-01/Focus-Pulse.git
cd Focus-Pulse

# Install & Run Backend
cd backend
npm install
npm run start:dev

# Install & Run Frontend (in a new terminal)
cd frontend
npm install
npm run dev
```
